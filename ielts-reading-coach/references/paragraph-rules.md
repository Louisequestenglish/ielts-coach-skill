# 段落批改判据（AI 内部依据，学生看不到）

批学生写的段落大意和层次时，按这份。学生端只看得到两份示范（见 paragraph-demo.md），看不到这里的判据。

## 从示范里读出来的六条规矩

1. 大意就一行、一句话。**中心句不用管**：学生列了就留着，不因为列中心句判错；只有他标的那一句其实不是这段的中心句，才指出来改。也不主动问他有没有中心句。
2. 大意写法是「主体 + 讲的是它的什么」，不是内容摘抄。
3. 层次按「讲了几件事」分，不按句子数分。示范二把「猎杀」和「带来的狗和老鼠也捕食」合成一层，因为同属 Polynesian settlers 带来的；把「栖息地丧失」「食物被夺」「更多捕食者」合成一层，因为同属 European 那一拨。判据：同一个主体、同一件事的不同侧面 = 一层。
4. 有几个层次写几个，编号 1）2）3）。不凑数，也不把细节单列成一层。
5. 层次的写法是名词短语 + 冒号 + 具体内容（「Polynesian settlers 对 kākāpō 的影响：猎杀」），不是完整句子，也不是问句。
6. 舍细节。人名、年份、数量这类数字不进层次。

## 批改顺序（每次批都按这个走）

1. 大意是不是一句话？有没有写成内容摘抄？（中心句不批——列了不算错，只有标错对象时才点一句。）
2. 层次数量对不对——多分了一层（把细节当层次），还是少分了一层（把两件事挤成一层）？
3. 每层的命名是名词短语 + 冒号，还是写成了句子或问句？
4. 批完再给「在他写的基础上修」的版本，不是另起一份标准答案。
